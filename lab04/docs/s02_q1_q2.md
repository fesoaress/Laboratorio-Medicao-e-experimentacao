# Lab04 S02 — Experimentos Q1/Q2 (Issue #81)

## Cenário
**Pergunta:** a taxa de falhas de CI excede 5%? **H₀:** p ≤ 0,05; **H₁:** p > 0,05; teste unilateral à direita, α=0,05.

- **Z para uma proporção:** Z = (k/n - p0) / sqrt(p0(1-p0)/n), p-valor unilateral por scipy.stats.norm.sf.
- **Binomial exato:** p-valor = P(K ≥ k | K ~ Binomial(n,p0)), via scipy.stats.binom.sf(k-1,n,p0).

## Método de simulação
- **Q1 — erro tipo I:** p_real = p0 = 0,05; calcular a fração de rejeições em 10.000 amostras sob H₀ verdadeira.
- **Q2 — poder:** 10.000 amostras para cada uma das seis probabilidades p_real: 5%, 7,5%, 10%, 12,5%, 15% e 20%. Os efeitos são, respectivamente, 0, 2,5, 5, 7,5, 10 e 15 pontos percentuais.
- **Referência:** n = 200 execuções por amostra. Amostras pequenas e problema da aproximação normal são abordados em Q3 (Issue #82).
- **Reprodutibilidade:** uma única sequência numpy.random.default_rng(42), sem reiniciar a semente entre os cenários.
- **Amostra pareada entre os testes:** ambos os testes recebem o *mesmo* número observado K de falhas em cada repetição. Sortear K ~ Binomial(n,p_real) equivale exatamente a sortear n Bernoullis independentes e somá-las para testes de uma proporção.
- **Decisão:** rejeitar H₀ quando p-valor < 0,05. A taxa de rejeição em p_real=p0 estima erro tipo I; quando p_real>p0, estima poder. O poder no efeito zero é a própria taxa de erro tipo I.

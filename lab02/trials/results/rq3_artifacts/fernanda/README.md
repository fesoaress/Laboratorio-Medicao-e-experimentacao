# Artefatos estruturais reconstruídos de Fernanda

Os quatro snapshots apontados pelos trials finais de Fernanda não foram
versionados em `lab02/trials/results/solutions/`. Para tornar a RQ3
reproduzível sem inventar código, esta pasta preserva cópias dos quatro códigos
preparatórios já versionados em `lab02/preparatory/fernanda/`.

Esses arquivos:

- passam os testes de aceitação correspondentes;
- reproduzem exatamente as métricas registradas para os trials finais;
- não são apresentados como snapshots originais do runner;
- são ligados aos trials e à proveniência pelo `manifest.csv`.

Essa reconstrução permite mensurar RQ3 sobre código real presente no
repositório. A ausência dos snapshots originais permanece registrada como
ameaça à rastreabilidade.

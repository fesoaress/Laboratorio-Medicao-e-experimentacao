## Dependências entre as etapas

- **S01:** finalizar objetivos, métricas, piloto e plano de análise antes da coleta completa.
- **S02:** capturar dados brutos e metadados antes de finalizar testes estatísticos e gráficos.
- **S03:** consolidar o relatório depois de validar resultados, verificar SQL e discutir ameaças à validade.
- **Final:** revisar em conjunto o relatório no template e os slides de 10 minutos antes de finalizar o PR.

## Responsáveis no GitHub

- As issues **#100, #103, #106 e #109** foram destinadas a **Islayder**, cujo usuário GitHub foi identificado como `Islayder`.
- Para **Vinícius** e **Fernanda**, a responsabilidade aparece no título/corpo, mas os assignees do GitHub precisam de seus usernames confirmados.
- Todas as issues começam abertas como tarefas propostas. Fechá-las exige evidência real: commit, arquivo revisado, resultado da execução ou aprovação do trio.
